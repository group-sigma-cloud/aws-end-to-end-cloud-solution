# Amazon S3 Documentation
 
## 1. Overview
 
Amazon Simple Storage Service (S3) is an object storage
service used to store and retrieve data.
 
## 2. Purpose in Group Sigma
 
S3 may be used to store application assets, project
files, static content, or other objects required by
the project.
 
The actual bucket purpose must be confirmed by the team.

## 4. Access Management
 
Document:
 
- Bucket-level permissions.
- IAM roles and policies.
- Bucket policies.
- Public access block configuration.
- Access logging, if configured.
 
Keep the bucket private unless public access is
explicitly required and approved.
 
## 5. CloudFront Integration
 
If the bucket is used as a CloudFront origin,
document the origin configuration.
 
For private S3 content served through CloudFront,
consider Origin Access Control (OAC).
 
OAC should be configured with an appropriate
bucket policy granting access to the intended
CloudFront distribution.
 
## 6. Encryption and Data Protection
 
Record:
 
- Encryption method.
- Key configuration, if applicable.
- Versioning settings.
- Data retention requirements.
- Backup or recovery approach, if applicable.
 
## 7. Verification
 
- Confirm the bucket exists.
- Confirm the intended objects are present.
- Confirm public access settings.
- Confirm encryption configuration.
- Test authorized access.
- Test denied access where appropriate.
- Verify CloudFront access if integrated.
